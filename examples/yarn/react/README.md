# Yarn Classic React example

This standalone example uses a Yarn Classic v1 lockfile and React with its
TypeScript definitions. The checked-in
[`.github/dependabot.yml`](.github/dependabot.yml) is generated by
`dependaconf`; Yarn projects are reported to Dependabot as the `npm`
ecosystem.

From the repository root, regenerate it with:

```sh
cd examples/yarn/react
cargo run --manifest-path ../../../Cargo.toml
```

No Yarn install is needed to generate the configuration.
