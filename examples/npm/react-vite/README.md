# Vite + React example

This directory contains a sample npm project with a Vite and React dependency
tree. It demonstrates the Dependabot configuration generated by `dependaconf`;
the checked-in [`.github/dependabot.yml`](.github/dependabot.yml) is the
generated output.

From the repository root, run:

```sh
cd examples/npm/react-vite
cargo run --manifest-path ../../../Cargo.toml
```

The command reads `package.json` and `package-lock.json` and creates or replaces
`.github/dependabot.yml`. No npm install is needed to generate the configuration.
