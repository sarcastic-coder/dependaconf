# Apollo Server example

This sample runs Apollo Server 5 with the Express 5 integration, GraphQL, and
TypeScript. Start the API with `npm run dev` and open
`http://localhost:4000/graphql`. The checked-in
[`.github/dependabot.yml`](.github/dependabot.yml) shows the configuration
generated by `dependaconf`.

From the repository root, regenerate that configuration with:

```sh
cd examples/npm/apollo-server
cargo run --manifest-path ../../../Cargo.toml
```

The command reads `package.json` and `package-lock.json` and creates or replaces
`.github/dependabot.yml`. No npm install is needed just to generate the config.
