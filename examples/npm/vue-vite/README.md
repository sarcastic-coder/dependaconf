# Vue 3 + Vite example

This sample npm project uses Vue 3, Vue Router, and Vite. The checked-in
[`.github/dependabot.yml`](.github/dependabot.yml) demonstrates the configuration
generated by `dependaconf`.

From the repository root, run:

```sh
cd examples/npm/vue-vite
cargo run --manifest-path ../../../Cargo.toml
```

The command reads `package.json` and `package-lock.json` and creates or replaces
`.github/dependabot.yml`. No npm install is needed to generate the configuration.
